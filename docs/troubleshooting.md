# 故障排查

## 收不到任何群事件（最常见）

机器人**未提审上线**，正式网关不会推送事件。逐一检查：

1. 在开放平台完成**机器人提审上线**
2. 确认机器人已被群主**"添加到群聊"**
3. 群设置里**"机器人主动在群聊内发言"**已开启

三者缺一都收不到。

!!! tip
    打开 `debug.log-events: true` 后重启，控制台会输出每个收到的 Dispatch 事件，零输出 = 没有事件推送。

## 连接后立刻关闭 / 4014

Identify 的 `intents` 订阅与机器人能力不匹配：检查平台「开发设置 → 接入方式 → WebSocket 与事件订阅」，确认机器人能力已开通群聊。

## 开了"获取群内全部消息"但仍收不到

开启全量后，群里每条消息（包括 @ 消息）都以 `GROUP_MESSAGE_CREATE` 全量事件推送（不再是 `GROUP_AT_MESSAGE_CREATE`），插件两种都处理。若仍零事件，回到上面三项检查。

## 回复报错 11273 / 鉴权失败

发消息 `Authorization` 头必须是 `QQBot <token>`（不是 `Bearer`），插件已按要求实现。若仍报错，确认 AppID / Secret 正确、token 未过期。

## 连不上网关

- `debug.probe: true` 打开后重启，查看 TLS 出口探针
- 检查开放平台 IP 白名单是否包含 BDS 服务器公网出口 IP

## 日志没有 access_token 获取记录

确认 `bot.app-id` / `bot.secret` 已填写，且当前读取的 `config.json` 就是你要改的那份（注意 plugins 下是否有多份插件目录）。

## 游戏消息不进群 / 进退服没通知

- 检查 `bot.groups` 是否配置了目标群——**为空时游戏→群方向不会发送任何消息**（QQ→游戏方向不受影响）
- 检查 `chat-format.start-with`：游戏消息必须以该前缀开头（默认 `#`）
- 检查 `join-leave.enabled` 是否为 `true`

## 指令面板没有命令 / 没更新

- 确认 `features.push-menu` 为 `true`
- 单面板 20 个命令上限，超出部分跳过（看日志告警）
- 修改配置后执行 `huhobot reload` 触发同步

## 热重载后出现重复消息

v1.2.1 已修复（旧网关连接强制断开 + 跨实例去重 + 监听器存活标志）。确保升级到最新版本；从旧版本升级后建议完整重启一次服务器清掉历史残留连接。

## 已知限制

- 群消息事件有两类：默认仅推 @ 机器人的消息（`GROUP_AT_MESSAGE_CREATE`）；群主开启"获取群内全部消息"后以 `GROUP_MESSAGE_CREATE` 全量推送，插件两种都处理。仅收到 @ 事件时，"全量转发"只会转发 @ 且非命令的消息
- 游戏 → 群方向不能修改原消息，只做转发
- 官方机器人拿不到真实 QQ 号，一切身份以 OpenID 为准
- 入群申请事件、禁言、审批接口需要机器人拥有**群管理员**身份
