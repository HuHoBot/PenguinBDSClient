# QQ 指令面板

插件会把内置命令与附属插件注册的命令自动同步到 **QQ 官方群聊指令面板**（客户端聊天框下方的指令按钮面板），帮助群成员发现和使用机器人能力。

总开关：`features.push-menu`（默认 `true`）。

## 工作方式

- QQ 客户端**同一场景只展示一个面板**，因此插件只维护**一个** group 场景面板
- 面板跨重启复用：按 remark 找回已有面板，`panel_id` 持久化在 `command-state.json`；找不到才创建
- 首次创建时绑定 `bot.groups` 配置的群（`target_type=specific`）；未配群则全局生效（`all`）
- **附属插件 `registerBotCommand(..., pushMenu=true)` 的命令优先**，内置命令按定义顺序填充剩余位置
- 旧版多面板格式会在启动时自动迁移并删除多余面板

## 官方限制

| 限制 | 处理 |
|---|---|
| 单面板最多 20 个命令 | 超出部分跳过并记录日志 |
| 命令名最长 14 字符 | 自动截断并告警 |
| 创建/修改 10 QPM、列表 30 QPM | 串行队列，避免并发冲突 |
| `only_admin` 仅管理员可点 | `permission > 0` 的命令自动映射 |

## 按命令隐藏

```json
"command-panel": {
  "查在线": false,
  "全量": false
}
```

- 只控制**面板展示**，命令本身照常可用
- 彻底关闭命令本身用 `commands.<命令名>: false`（同时也会从面板移除）
- `commands.<命令名>: false` 关闭的命令不会同步到面板

## 常见问题

- **面板里只显示了部分命令**：20 个上限；用 `command-panel.<命令名>: false` 隐藏不常用的，给重要命令腾位置
- **面板没更新**：改动后 `huhobot reload`；面板变更走 `PUT /v2/panels/{panel_id}`，本地镜像一致时会跳过请求
